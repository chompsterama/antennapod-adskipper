AntennaPod Integration Blueprint

How to incorporate automated host-read ad skip pipeline directly into Android client builds (e.g., AntennaPod Android app).

1. Architectural Flow

  1. Pre-download / Stream Hook: AntennaPod fetches standard RSS MP3 enclosure.
  2. Lightweight Local STT: Run lightweight Whisper.cpp / Vosk Android library locally, OR delegate to remote backend service.
  3. LLM Classifier & Acoustic Peak Check: Pass timestamped transcript snippets to Gemini Flash API to detect sponsorship trigger keywords ("sponsored by", "use promo code").
  4. Chapter Insertion: Dynamically insert generated Skip Zones into Media3 / ExoPlayer track metadata.

2. Android ExoPlayer Auto-Skip Hook Example

// ExoPlayer PositionDiscontinuity Listener
player.addListener(new Player.Listener() {
    @Override
    public void onPositionDiscontinuity(
        Player.PositionInfo oldPosition, 
        Player.PositionInfo newPosition, 
        int reason
    ) {
        long currentMs = player.getCurrentPosition();
        AdSegment ad = findActiveAdSegment(currentMs);
        
        if (ad != null && isAutoSkipEnabled) {
            // Seek past the host-read sponsorship block
            player.seekTo(ad.getEndTimeMs() + 500);
            showToast("Skipped Host-Read Ad (" + ad.getSponsorName() + ")");
        }
    }
});

3. Gemini API Detection Prompt Schema

POST https://generativelanguage.googleapis.com/v1beta/models/gemini-3-flash-preview:generateContent
System Instruction: "You are an ad detection classifier for podcast transcripts. Return JSON containing detected ad time intervals and confidence scores."
Request Body:
{
  "contents": [{
    "parts": [{ "text": "Analyze transcript with timestamps: ..." }]
  }],
  "generationConfig": {
    "responseMimeType": "application/json",
    "responseSchema": {
      "type": "ARRAY",
      "items": {
        "type": "OBJECT",
        "properties": {
          "startTime": {"type": "NUMBER"},
          "endTime": {"type": "NUMBER"},
          "type": {"type": "STRING"},
          "confidence": {"type": "NUMBER"}
        }
      }
    }
  }
}
